# 📊 Data Analysis Practice — DA5

데이터 분석가 과정에서 진행한 실습 및 프로젝트 모음입니다.  
Python(Pandas), SQL(BigQuery)을 활용한 데이터 전처리, 탐색적 분석, 고객 세그멘테이션을 다룹니다.

---

## 🗂️ Structure

```
DA5/
├── 01_cars/                        # 자동차 데이터 분석
├── 02_churn/                       # 고객 이탈 분석
├── 03_fraud/                       # 사기 탐지 분석
├── 04_trip/                        # 이동 패턴 분석
└── 05_customer_segmentation/       # 고객 세그멘테이션 프로젝트 (SQL)
```

---

## 📁 Contents

### 01 · Automotive Data Analysis
`Python` `Pandas`
- 자동차 관련 데이터셋 탐색 및 분석

### 02 · Customer Churn Analysis
`Python` `Pandas`
- 고객 이탈 여부 분석 및 패턴 탐색

### 03 · Fraud Detection Analysis
`Python` `Pandas`
- 이상 거래 탐지를 위한 데이터 분석

### 04 · Trip Pattern Analysis
`Python` `Pandas`
- 이동 데이터 기반 패턴 분석

### 05 · Customer Segmentation Project
`SQL` `BigQuery`
- 541,000건의 이커머스 거래 데이터 전처리 (결측치 · 중복 · 이상값)
- RFM(Recency, Frequency, Monetary) 스코어 산출
- 구매 다양성, 평균 구매 주기, 취소 경향성 등 추가 feature 추출
- BigQuery를 활용한 고객 세그멘테이션 파이프라인 구성
